# ashDuels

  Challenge other players to fair, self-contained 1v1 duels.

  - /duel <player> sends a clickable duel request; the target can accept or deny.
  - Duels take place in a dedicated arena world with a real world border, so nothing outside is affected.
  - Other players can spectate ongoing duels via a chat button.
  - The winner is fully healed and gets a timed loot phase to collect the loser's drops.
  - Duels end automatically after a configurable time limit if no one dies.
  - All messages, timers and arena settings are configurable.
